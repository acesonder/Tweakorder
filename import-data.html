🔧 Troubleshooting Guide

  • Connection Failed: Check that your database server is running and credentials are correct
  • Import Error: Ensure database_schema.sql is imported first before other files
  • Permission Denied: Verify your database user has CREATE, INSERT, and DROP privileges
  • Table Already Exists: Use "Clear Database" to remove existing tables, or manually drop them
  • Foreign Key Errors: Import files in the recommended order: schema → harm reduction → demo
  • Syntax Errors: Ensure you're using MySQL/MariaDB and the SQL files are not corrupted
